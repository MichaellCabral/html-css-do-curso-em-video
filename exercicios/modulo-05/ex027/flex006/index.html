Flexible Box

Justify Content: Alinha os itens dentro do contêiner ao longo do eixo principal. O eixo principal é definido pela propriedade flex-direction. Os valores comuns para justify-content incluem:

  • flex-start: Alinha os itens no início do contêiner.
  • flex-end: Alinha os itens no final do contêiner.
  • center: Centraliza os itens dentro do contêiner.
  • space-between: Distribui os itens com espaço igual entre eles, sem espaço nas extremidades.
  • space-around: Distribui os itens com espaço igual ao redor deles, incluindo nas extremidades.
  • space-evenly: Distribui os itens com espaço igual entre eles, incluindo nas extremidades.
align-items: Alinha os itens dentro do contêiner ao longo do eixo transversal (cross axis). O eixo transversal é perpendicular ao eixo principal. Os valores comuns para align-items incluem:
  • stretch: Estica os itens para preencher o contêiner (padrão).
  • flex-start: Alinha os itens no início do contêiner.
  • flex-end: Alinha os itens no final do contêiner.
  • center: Centraliza os itens dentro do contêiner.
  • baseline: Alinha os itens pela linha de base do texto.
align-content: Alinha as linhas dentro do contêiner quando há espaço extra no eixo transversal (quando eles estão empacotados). Os valores comuns para align-content incluem:
  • stretch: Estica as linhas para preencher o contêiner (padrão).
  • flex-start: Alinha as linhas no início do contêiner.
  • flex-end: Alinha as linhas no final do contêiner.
  • center: Centraliza as linhas dentro do contêiner.
  • space-between: Distribui as linhas com espaço igual entre elas, sem espaço nas extremidades.
  • space-around: Distribui as linhas com espaço igual ao redor delas, incluindo nas extremidades.
  • space-evenly: Distribui as linhas com espaço igual entre elas, incluindo nas extremidades.
