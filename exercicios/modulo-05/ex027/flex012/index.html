Propriedade flex

A propriedade flex é uma forma abreviada (shortland) de definir as propriedades flex grow, flex shrink e flex basis em um único valor.

Ela é usada para controlar o crescimento, encolhimento e a base dos itens no contêiner flexível.

flex: 0 1 auto; /* valor padrão */
flex: initial; /* equivalente a flex: 0 1 auto */
flex: auto: /* equivalente a flex: 1 1 auto */
flex: none; /* equivalente a flex: 0 0 auto */ o mais rígido, não cresce nem encolhe.
flex: 3: /* equivalente a flex: 3 1 auto */ o item pode crescer três vezes mais do que os outros itens.
