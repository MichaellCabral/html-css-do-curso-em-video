Flexible box 010

flex grow e flex shrink

flex shrink

quando o espaço disponível é menor que o espaço necessário pelos itens, os itens com flex shrink podem encolher para se ajustar.

número zero para flex shrink significa que o item não pode encolher.

flex grow

quando o espaço disponível é maior que o espaço necessário pelos itens, os itens com flex grow podem crescer para ocupar o espaço disponível.

número zero para flex grow significa que o item não pode crescer.
