Flexible box 011

flex shrink e flex grow com proporcionalidade

Os valores de flex shrink e flex grow podem ser definidos em proporções para controlar como os itens se comportam ao redor do espaço disponível.

adicionalmente, os valores podem ser especificados como números para determinar a proporção de crescimento ou encolhimento dos itens.

a partir do número um definimos a proporção de crescimento ou encolhimento dos itens.
