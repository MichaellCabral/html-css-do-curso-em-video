Teste de Flexbox

O conteúdo deste desta pagina é apenas para testar o comportamento do Flexbox, principalmente em telas menores, como as de celulares. O menu deve se adaptar e ficar mais fácil de usar em dispositivos móveis. utilizei media queries para garantir que o layout se ajuste adequadamente em diferentes tamanhos de tela, proporcionando uma experiência de usuário consistente e agradável. O Flexbox é uma ferramenta poderosa para criar layouts flexíveis e responsivos, permitindo que os elementos se organizem de maneira eficiente, independentemente do tamanho da tela.
