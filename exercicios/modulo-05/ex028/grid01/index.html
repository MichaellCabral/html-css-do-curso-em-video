all stretch

O stretch de ser substituído por normal

  • align-items: stretch (valores padrão) serve para alinhar os itens dentro das linhas do grid
  • justify-items: stretch (valores padrão) serve para alinhar os itens dentro das colunas do grid
  • align-content: stretch (valores padrão) serve para alinhar as linhas do grid
  • justify-content: stretch (valores padrão) serve para alinhar as colunas do grid
