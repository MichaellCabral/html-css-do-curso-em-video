Grid Layout frações

Frações

As frações são representadas por fr, é uma unidade de medida exclusiva do grid, ela representa uma fração do espaço disponível, ou seja, se eu tenho 3fr, cada fr representa 1/3 do espaço disponível, se eu tenho 4fr, cada fr representa 1/4 do espaço disponível, e assim por diante.

As frações são muito úteis para criar layouts responsivos, pois elas se adaptam ao tamanho do container, ou seja, se eu tenho um container com 3fr, e o container tem 300px de largura, cada fr representa 100px, se o container tem 600px de largura, cada fr representa 200px, e assim por diante.
